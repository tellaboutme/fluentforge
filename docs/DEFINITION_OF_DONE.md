# Definition of Done

A feature is done only when:

- the learner outcome and acceptance criteria are documented;
- domain behavior is implemented without placeholders;
- public contracts are typed and version-safe;
- loading, empty, success, retry, and failure states exist;
- accessibility has been checked;
- mobile and desktop behavior has been inspected;
- telemetry avoids sensitive content by default;
- unit/integration tests cover normal and important edge cases;
- relevant end-to-end flow passes;
- curriculum/prompt fixtures are validated when affected;
- documentation and current status are updated;
- no new secret, PII, or raw learner media leak exists.
