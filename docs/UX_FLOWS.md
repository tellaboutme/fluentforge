# UX Flows

## First run

1. Welcome: “Build English you can use.”
2. Select goals and daily time.
3. Explain that skills are measured separately.
4. Complete 10–20 minute adaptive diagnostic.
5. Optional microphone check and short speaking sample.
6. Receive profile: strengths, uncertainty, first priority.
7. Start a five-minute first lesson immediately.

## Daily home

Show:

- today's estimated duration;
- due reviews;
- primary learning objective;
- skill balance;
- one clear Start button;
- optional switch to a shorter plan.

Do not show a wall of charts before the learner acts.

## Activity player

Persistent areas:

- objective;
- progress within current session;
- instructions;
- content/task;
- answer controls;
- hint with visible evidence cost;
- report issue;
- accessibility controls.

## Feedback

Order:

1. Did communication succeed?
2. What was done well?
3. Up to three priority improvements.
4. Original → corrected → explanation.
5. One immediate retry or transfer prompt.
6. What will return in review.

## Progress

Use skill map and plain language:

- “You can…” supported outcomes;
- “You are developing…”;
- “We still need evidence for…”;
- examples from past work;
- monthly benchmark comparison.

## Visual direction

- calm, adult, modern;
- high information clarity;
- minimal gamification;
- dark and light themes;
- excellent mobile recording workflow;
- charts accompanied by text explanations;
- no red/green-only meaning.
