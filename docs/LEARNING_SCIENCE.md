# Learning Design Principles

## Practice architecture

Each learning cycle should include:

1. **Comprehensible input** — material slightly above current independent ability.
2. **Noticing** — focus attention on useful language and patterns.
3. **Retrieval** — recall without seeing the answer.
4. **Production** — use the language to express personal meaning.
5. **Feedback** — identify a small number of high-value improvements.
6. **Repetition with spacing** — return after increasing intervals.
7. **Variation and transfer** — use the same knowledge in a new task.
8. **Reflection** — learner states what became easier and what remains unclear.

## Exercise design rules

- Recognition exercises introduce and diagnose; they cannot alone establish productive mastery.
- Multiple choice should include meaningful distractors based on known misconceptions.
- Typing and speaking tasks should appear early, with scaffolding that fades.
- Hints reduce evidence strength and must be recorded.
- Immediate retries aid learning but delayed unseen retrieval supplies stronger mastery evidence.
- Interleave related but confusable structures.
- Avoid presenting incorrect language repeatedly without clear correction.
- Use personal relevance, but never invent sensitive personal facts.

## Error handling

Rank errors by:

1. meaning blocked or changed;
2. repeated learner pattern;
3. target of the current activity;
4. high-frequency usefulness;
5. social/pragmatic risk;
6. advanced style refinement.

For A1–B1 output, normally correct no more than three priority patterns at once. Preserve the learner's message and show an improved version. At C1–C2, feedback may address nuance, rhetoric, register, and economy.

## Desirable difficulty

A task should not be considered well calibrated merely because it feels comfortable. Target roughly:

- high success for new supported material;
- moderate challenge for retrieval;
- lower but non-demoralising success for transfer and diagnostic tasks.

Exact thresholds belong in configuration and should be validated with usage data.

## Extensive practice

The system must encourage substantial reading and listening for meaning. Not every sentence should become an exercise. After input, select a few high-value items and ask for summary, reaction, prediction, or application.
